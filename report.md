# Анализ данных киноиндустрии


## Описание
Цель этого проекта показать ключевые тренды киноиндустрии,
выявить самы популярные жанры, создать связь между бюджетом и прибылью, 
а также отследить изменения популярности фильмов по возрасту.

## Данные
Полученный датасет имееет `45 465` рядков и `24` рядка.
Основные колонки датасета:
  
- `title`: Название фильма
- `vote_average`: Средняя оценка 
- `vote_count`: Кол-во оценок
- `budget`: выделенный бюджет фильма
- `profit`: чистый доход 
- `overview`: короткое описание 
- `spoken_languages	`: кол-во языков 

### Очитска данных

1. Удалены записи без дат.
2. Жанры JSON-формату розделены на отдельные рядки.
3. Добавлены новые колонки: `"release_year"` и `"profit"`
